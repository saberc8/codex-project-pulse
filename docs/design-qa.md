# Project Pulse 验收记录

公开记录只保留匿名测试数据与技术结果，不包含真实项目名、聊天内容、用户截图或本机路径。

## 0.2.1 — 2026-11-18

视觉收敛：暖中性底色、中性灰、1px 细线，去掉阴影、渐变和彩色底块拼接；状态改用整张卡片的淡色底与边框、浅色计数胶囊和行内标签（蓝未读、青绿运行中、淡橙待办、红失败或逾期）。总览首屏的“待看结果”列表只在有未读或近 24 小时失败时出现，最多 5 行；待办移到右上角「待办 N」按钮，点击或按 T 打开居中弹窗，可勾选、编辑与展开已完成（弹窗内不重复放新建入口），编辑结束后回到列表，导航去掉“我的待办”；内容区取消最大宽度；项目区改用与其他视图相同的分段筛选，数量为 0 的变灰，卡片不再重复列待办；会话行悬停时，时间位置换成关联待办加号。未读会话用带光环的 8px 蓝点、加粗标题和浅蓝行底，待处理里的「新结果」为实心蓝标签；本轮完成、已中断与状态未知统一为浅灰点，具体状态见悬停提示。移除结果速览抽屉，以及待办页里使用原生下拉的快速添加栏。

检查：3 个前端脚本语法检查、2 个 Node 测试通过。本机 Chrome（Playwright）预览，真实数据只在本机查看，不留截图：1440px 项目网格 4 列，末行列对齐；弹窗内编辑后按 Esc 回到列表，直接从卡片新建按 Esc 关闭，T 键打开弹窗；390px 为单列，320 / 360 / 390 / 760 / 1440px 的 `scrollWidth` 均等于视口宽度（≤480px 隐藏刷新按钮、待办按钮只留图标与数量，360px 以下导航可横向滑动）；悬停加号能打开预选项目与会话的待办表单。通过拦截快照注入匿名的未读、失败、运行中和逾期待办，确认待看结果排序、待办弹窗的高优先 / 逾期 / 截止标签、标签颜色、“还有 N 项”入口和卡片状态底色正常，未写入真实数据。原生 Codex 入口未在本版验收。

## 0.1.11 — 2026-11-17

本版不改变页面布局。入口图标改用浅 / 深色 PNG，服务器初始化与工具列表采用相同的当前未读状态；HTML 资源使用 `ui://project-pulse/dashboard-0.1.11.html`。

发布前检查：15 个 Python 数据与协议测试、2 个 Node 状态与 bridge 测试、4 个前端脚本语法检查通过。Python 测试包含临时目录搬迁启动、初始图标与工具图标一致及版本化 UI 资源验证。浅色未读 PNG 已直接查看，图形与蓝点完整、背景透明。GitHub 市场安装在仓库发布后执行，结果以 Release 记录为准。

原生界面边界：用户截图显示当前顶部导航与系统入口选中背景，但原生 P 仍为线性，状态点呈灰色。PNG 修改仅为兼容尝试。工具禁止访问 Codex 原生窗口，因此本版没有完成原生蓝点颜色、实时刷新及选中实心效果验收；没有擅自重启整个桌面 App。

## 既有页面验收

以下为本地版本已完成的 Chrome 预览检查，不能解释为原生窗口验收。本版只修改入口资产、协议首连状态与发行元数据，布局与交互沿用已验证实现。

| 场景 | 已观察结果 |
| --- | --- |
| 顶部导航，1512 / 1200 / 736 / 390 / 320px | 分别为 6 / 5 / 3 / 2 / 1 列，无横向溢出；四个导航与设置保持同排 |
| 宽屏与末行 | 卡片均分可用宽度，末行及搜索少量结果保持列对齐 |
| 导航选中 | 高亮与 `aria-current` 一致，页面内总览选中为实心 P |
| 真实未读语义的隔离样例 | 全部已读后提示消失；运行中仍有未读时保留提示；未知时隐藏提示且完成未读显示 `—` |
| 导航与自动刷新 | 切换视图不清除未读；会话浮层在刷新后保持展开 |
| 标题跳转 | 卡片、会话列表、收件箱和待办关联会话发送正确打开请求，无结果预览弹窗 |
| 待办绑定 | 行尾加号预选相应项目与会话；切换项目清空不兼容会话 |
| 共享表单组件 | 搜索、无匹配项、行内错误、优先级与状态选择、今天 / 清除、编辑和持久化通过 |
| 键盘 | Escape 先关下拉再关表单；Tab 在表单内循环；日历月份切换通过 |
| 320×568 表单弹层 | 下拉和日历处于视口内，可滚动，无横向溢出 |

需要写入的页面检查使用 Alpha / Beta 等虚构项目和独立 SQLite；不在用户真实待办、置顶或未读状态上验收。

仓库提供 `docs/ci.example.yml` 作为 GitHub Actions 模板。首次发布所用凭据缺少 `workflow` scope，因此模板未启用，不能把本地检查结果标为云端 CI 通过。

## 自动验证范围

- Codex 原库只读不变；嵌套项目归属、归档与子代理过滤。
- 当前桌面阅读索引优先于陈旧 SQLite receipt；账号或主机不明确时未知。
- 完成本轮与项目完成分离；历史处理记录与真实未读分离。
- 待办跨项目绑定拒绝、持久化、归档后完成、删除。
- Host / Origin / 写入 token 校验。
- MCP 初始化、工具发现、当前入口图标、工具列表变更通知。
- 含空格的新目录按真实清单启动，无原路径或符号链接依赖。
- 自包含 UI 资源、升级后资源地址变化、旧 URI 拒绝。
- 前端未读状态、favicon 和 MCP bridge。

## 安装验收的三层

1. **磁盘安装**：检查版本、安装路径、文件与清单；安装成功不代表旧进程已更新。
2. **独立进程**：从安装副本启动 MCP 并核对初始化、工具及资源；这不代表当前桌面已切换进程。
3. **原生画面**：完整重启 App 后检查系统入口与面板。工具无法访问时如实保留未验证状态。
